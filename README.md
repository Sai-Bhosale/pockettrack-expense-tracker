# PocketTrack — Personal Expense Tracker

PocketTrack is a responsive personal expense tracker built using HTML, CSS, and JavaScript. It helps users record expenses, view spending summaries, and understand their spending by category.

## Features

- Add and delete expenses
- Filter expenses by month
- Search expenses by name, category, or note
- View total spending and transaction count
- Identify the biggest expense
- Visualize spending with a doughnut chart
- Export expense records to CSV
- Save records in browser local storage
- Responsive layout for desktop and mobile
- Keyboard-friendly form controls and focus indicators

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## Live Demo

https://sai-bhosale.github.io/pockettrack-expense-tracker/

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Keep an internet connection available for the Chart.js library.

## Data Storage

Expenses are stored in the browser's local storage on the current device and browser. They are not synced to an online database.

## Project Purpose

This project demonstrates front-end development, form validation, client-side data handling, data visualization, CSV export, and responsive interface design.
